# Code of Conduct

Participants are expected to communicate professionally and respectfully. Harassment, threats, discriminatory abuse, sexualized harassment, deliberate disruption, and publication of another person's private information are not acceptable.

This applies to repository issues, pull requests, discussions, and other spaces used to represent the project.

For ordinary moderation questions, contact the repository maintainer through the account associated with this repository. Do not place sensitive personal information in a public issue. A private contact route should be used for reports that cannot safely be made public.

This document uses the principles of the Contributor Covenant 2.1; see <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
