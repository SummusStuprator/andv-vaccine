This directory contains the HLA types generated for the paper:

Immune diversity sheds light on missing variation in worldwide genetic diversity panels.
Abi-Rached L, Gouret P, Yeh J-H, Di Cristofaro J, Pontarotti P, Picard C, and Paganini J.

Published: October 26, 2018 DOI: 10.1371/journal.pone.0206512

https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0206512

The table listing the HLA types contains the following information:
 "Region": Region of the world, as defined in the 1,000 Genomes Project
 "Population": Name of the population, as defined in the 1,000 Genomes Project
 "Sample ID": Sample identification name, as defined in the 1,000 Genomes Project
 "HLA-A 1" "HLA-A 2": HLA-A genotype
 "HLA-B 1" "HLA-B 2": HLA-B genotype
 "HLA-C 1" "HLA-C 2": HLA-C genotype
 "HLA-DQB1 1" "HLA-DQB1 2": HLA-DQB1 genotype
 "HLA-DRB1 1" "HLA-DRB1 2": HLA-DRB1 genotype

Example: the sample "HG01879" belongs to the "AFR" region and to the "ACB" population and the corresponding HLA class I genotype is  A*23:01/*68:02, HLA-B*13:02/*42:01, HLA-C*08:04/*17:01, and the corresponding HLA class II genotype is HLA-DQB1*02:02/*04:02, HLA-DRB1*03:02/*09:01.

The HLA types listed in this directory are also available as a supplementary Table of the paper mentioned above (S2 Table, https://doi.org/10.1371/journal.pone.0206512.s010 ).

From the paper supplementary info:
This table gives the final HLA types in our analysis for the 2,693 donors of the 1,000 Genome Project panel based on PolyPheMe Software.
All analyses in this study were performed with PolyPheMe v1.2 on exome sequences using the IMGT database 3.28 as reference [1]. The HLA version of PolyPheMe software (Xegen, France) is a novel in silico solution to perform highly accurate HLA typing (HLA-A, -B, -C, -DRB1, and -DQB1 in this study) from a wide range of sequence data, including targeted, whole exome, or whole genome sequencing. Depending on the type of sequence data used, PolyPheMe provides different levels of typing resolution: for example, allotype-level typing if exon sequences are used (Field 2 or 3 in the HLA nomenclature [2]) or full allele-level typing if exon and intron sequences (whole genome or targeted approaches) are used (Field 4 in the HLA nomenclature [2]). More information about PolyPheMe is available in the supplement of the paper mentioned above and licenses can be obtained by contacting XEGEN company (direction@xegen.fr).

Additional data formats can be obtained by contacting Laurent Abi-Rached (laurent.abi-rached@univ-amu.fr) or Julien Paganini (julien.paganini@xegen.fr).
